# KS Digital

A premium, light-theme, app-first digital services experience built with Next.js and React. The responsive website and installable PWA share one codebase.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Notes
- Portfolio entries are labelled as concept/demo projects until verified live project URLs and ownership are provided.
- Contact form currently uses a client-side mailto flow; connect a server endpoint before production use.
- OTP authentication is not enabled by this starter. Add Twilio Verify through a server-side API and store credentials in environment variables; never expose secrets in browser code.
- Installable PWA metadata and icon included.
